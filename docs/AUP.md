# Política de Uso Aceptable (AUP)

Este documento establece las condiciones bajo las cuales se permite el uso del sistema *haiti-tts* y sus componentes (API, modelos de voz, datasets, interfaces).

## 1. Propósito del sistema

El sistema está diseñado para fines educativos, comunitarios, investigativos y de accesibilidad lingüística. No debe utilizarse para actividades ilegales, discriminatorias o que violen derechos de terceros.

## 2. Comportamiento esperado

- Usar el sistema de forma ética y respetuosa.
- No manipular ni alterar los modelos para generar contenido ofensivo, engañoso o violento.
- No intentar acceder a datos, configuraciones o recursos no autorizados.

## 3. Restricciones de uso

- Prohibido el uso comercial sin autorización explícita.
- Prohibido el uso para vigilancia, discriminación o manipulación política.
- Prohibido el entrenamiento de modelos derivados sin consentimiento de los autores originales.

## 4. Protección de datos

- Los datos de voz, texto y metadatos deben manejarse conforme a las leyes de privacidad aplicables.
- Se requiere consentimiento informado para todo dato personal o sensible.

## 5. Sanciones

El incumplimiento de esta política puede resultar en la revocación del acceso, reporte a autoridades competentes o acciones legales.

## 6. Contacto

Para dudas o solicitudes de uso extendido, contactar a los responsables del proyecto.
